## 모바일에서 명시적으로 정한 차이

- 금액은 UI에 표시한 **원 단위**로 입력하며 서버 계약과 동일한 정수로 보낸다. 웹의 만원 입력 환산과 다르다.
- 위치를 선택하지 않으면 주소/좌표를 비워둘 수 있다. 특정 사무실을 사용자의 매물 위치로 저장하지 않는다. 지도 초기 중심은 지도 표시 기준일 뿐 매물 데이터가 아니다.
- 현재 위치 요청 실패를 실제 위치로 오인하지 않도록 오류를 표시하고 주소 검색을 계속 제공한다.
- 사진은 시스템 선택기에서 한 장씩 추가하며 각 요청의 오류를 표시한다. 다중 업로드 대기열은 구현하지 않았다.
- 제공 항목을 선택하는 사용자 양식은 CRUD와 순서 편집을 지원한다. 배포 API는 새 사용자 질문 문자열을 받지 않으므로 직접 질문 작성은 제공하지 않는다. 예전 직접 질문이 포함된 양식은 파괴적인 재저장을 막는다.
- 지도 시설 분석은 위치를 선택한 후 버튼으로 요청한다. 사용자가 지도를 스크롤하는 동안 계속 외부 조회를 보내지 않는다.

## 자동 검증

`ScreenStateTest`는 실제 Compose 화면 렌더링 시험이 아닌, 화면 요청/동작 상태의 코루틴 단위 테스트다.

1. 빈 서버 목록은 오류가 아닌 정상 빈 화면 상태가 된다.
2. 네트워크 실패 후 재시도 성공 시 오류가 제거된다.
3. 연속 새로고침은 이전 요청을 취소하고 최신 응답만 반영한다.
4. 저장 버튼을 연속 눌러도 진행 중에는 중복 요청하지 않는다.
5. 화면에서 벗어나 코루틴이 취소되면 성공/실패 안내로 오인하지 않는다.
6. 필드 오류와 위치 권한 해결 안내가 사용자에게 전달된다.
7. 잘못된 비밀번호의 401 응답을 세션 만료 안내로 바꾸지 않는다.
8. 주변 조회 중 위치·반경·카테고리가 바뀌면 이전 결과를 표시하지 않는다.
9. 이미 바뀐 조회 조건의 실패 응답도 현재 화면의 오류로 표시하지 않는다.

위 9개는 `./gradlew :composeApp:testDebugUnitTest --tests 'kr.jachwisunbae.app.ui.ScreenStateTest' --console=plain`으로 모두 통과했다. 이 명령은 Android JVM 단위 테스트이며 iPhone 실제 화면 조작 검증과는 별개다.

`iosAppUITests/SmokeTests.swift`를 iPhone 18 Pro / iOS Simulator 27.0에서 실행해 **XCTest 1개 성공, 0 실패(36.628초)**를 확인했다. 닉네임은 Compose `testTag("login-nickname")`로 찾는다. 검증한 실제 UI 동작은 닉네임 입력, 비밀번호 보기 토글, 개발 API 로그인, 빈 매물 목록, 프로세스 종료·재실행 후 Keychain 세션 복원, MapKit 지도 렌더링, 로그아웃이다. 원본 증거는 `.tools/ios-ui-signed.log`와 `.tools/ios-ui-signed.xcresult`이며, 보존한 [빈 목록 화면](verification/ios-empty-properties.png)과 [MapKit 화면](verification/ios-mapkit.png)도 확인할 수 있다.

초기 미서명 Simulator 실행은 Keychain entitlement 누락(`-34018`)으로 실패했다. 로컬 ad-hoc 서명을 적용한 뒤 위 전체 흐름이 통과했다. 이 실패를 터치 전달이나 로그인 코루틴 문제로 단정하지 않는다. 정확한 실행 명령과 서명 조건은 [BUILD_REPORT.md](BUILD_REPORT.md)를 따른다.

별도로 실제 개발 API 테스트 **2개**가 매물·사진·체크리스트·메모 CRUD, 단계 적용과 집계, PDF 생성, 주소·주변 시설 응답을 검증했다. 이는 모바일 화면으로 각 기능 전체를 조작했다는 뜻이 아니다. 테스트는 고유 닉네임의 개발 계정을 사용했고 생성한 테스트 매물·체크리스트를 정리했다. 계정 삭제 API가 없어 테스트 계정은 남는다. 운영 API에는 변경 요청을 보내지 않았다.

## 출시 전 기기 점검

- iPhone 노치/홈 인디케이터, Android 제스처/3버튼 내비게이션, 키보드 표시 중 저장 버튼 접근.
- 작은 화면과 큰 글자에서 체크 상태 버튼, 긴 질문, 긴 주소, 사진 전체 보기, 비교 가로 스크롤.
- Android 시스템 뒤로가기, iOS 상단 뒤로가기/지원되는 내비게이션 제스처, 로그아웃 후 이전 개인 화면 접근 불가.
- 사진 권한 허용/취소, 현재 위치 정밀/대략/거부, 위치 서비스 끔, 파일 저장 취소, 공유 시트 취소.
- 폼 작성 중 네트워크 단절에서 입력 유지와 재시도; 로그인 만료 후 비밀번호/개인 기록 노출 여부.
- 양식 교체 후 공통 시스템 항목 상태/메모 승계, 제외 항목 제거, 기존 양식 삭제 후 적용 기록 유지.
- 비교 PDF의 선택 순서, 한글 폰트, 사진/메모/단계별 체크 내용, 삭제된 기록 제외.

아직 편집 화면의 미저장 변경 이탈 확인은 없다. 상단 또는 시스템 뒤로가기로 폼을 나가기 전에 저장해야 한다. 서버에 저장되지 않은 폼 초안을 계정 간 공유하거나 영구 저장하지 않는다.
